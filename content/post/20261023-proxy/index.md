A serious vulnerability was found a couple of days ago that affects around 70% of the web. INFN has taken this very seriously and has been updating systems rapidly, which is why some services may not have worked over the last few days.

Unfortunately, it is not possible to secure everything immediately, so extra protection has been added to some services. For now, these can only be accessed from the INFN network (including our Department) or via VPN. I am not sure of the current status at UPO, PoliTo, or the math department (let me know)

Notably, the **mission portal** is no longer accessible from outside.

If you cannot reach these services, I recommend using a proxy via ssh.  
You can find [here](INFN_SSH_SOCKS_Proxy_Guide.pdf) a PDF with detailed instructions. From the terminal, you will need to use the username and password provided for your Torino unix accounts (not your portal credentials).

Let me know if anything is unclear.

Godspeed
